No trimming or arithmetic ceiling was inferred.

Full-request rates use plain actual server requests on the already-consumed natural12 DEV prompts, four per domain, with two same-process warmups and five alternating paired repetitions. There are700actual responses,600measured across plain/diagnostic companions, all target-identical. Diagnostic full-draft host spans include generation, catch-up and acceptance; asynchronous work can be charged at synchronization. They are not GPU timings. W1's full-draft host span falls by 11.0% [95% 9.3–12.8%]. Confidence intervals resample complete prompts/domains and repetitions together, preserving pairs; they do not represent new training seeds or generalization beyond these consumed cohorts. Sampled device memory includes the desktop baseline and can miss transients; it is not an exact allocator peak.

The retained runtime combines conditional copy simplification, tiled known-bound quantization with finite checks, integer code-sum completion, and joint gate/up DP4A execution. It honors requested vocabulary rows and removes final-layer anchor FFN work only after final attention/cache writes, with embedding/nextn requests excluded. The candidate remains packed W1 FFNs with G4/D8 codes, F32 scales/midpoints/gains and trained norms, frozen Q4_0 fusion/attention, shared Q6_K head/embedding and F16 KV. Model bytes, learned bounds, features/topology, target, verifier, context4096, greedy depth2, output reserve256 and consistent decode32 stay fixed.

The short unchanged and final Nsight traces identify actual N3, DP4A vector dispatch in both W1 and Q4, one replayed draft CUDA graph, attention/head/sampler costs and context-dependent graph updates. The twelve planned CONT nodes alias in production rather than execute twelve copy kernels; six named copies appear in callback audit graphs. Fixed clipping originally still scanned maxima. The retained tiled quantizer removes that scan, maintains gained finite validation and uses up to432bytes of reusable partial-sum workspace. Joint gate/up shares codes while keeping integer dots and affine ordering exact. Head pruning does not save a third of head latency: the grouped Q6_K kernel shares weight reads.

The tested native-INT4 PTX interface compiles on SM120a but lowers to two signed INT8 MMA sites. No SM100-only facility, driver/permission change or NVFP4 grid change was used.
