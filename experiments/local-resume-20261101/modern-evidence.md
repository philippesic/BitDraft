## Workaround and performance limits

The conservative opt-in is `GGML_CUDA_DECODE_CONSISTENT=32` in the loaded patched CUDA library. The preserved [patch](/home/philip/binary-eagle-decoding/runs/spec-cuda-fix-20261031/cuda-decode-consistent.patch) disables CUDA fusion when enabled; for small batched matrix products it applies single-token MMVQ/MMVF arithmetic per independent column, keeps the flash-attention vector path for Qwen3.5 F16-KV decode batches, and fixes attention splitting to one partition. The [live-library proof](/home/philip/binary-eagle-decoding/runs/spec-cuda-fix-20261031/live-library-proof.json) records the environment override and loaded library hash `ce3cb04b2fb1145e9950e5924b61333da61d18d2ed6fd0458446c015ac8e508c`. Build configuration is CUDA architecture 120, CUDA 13.1, Release; the exact build command is in [configure-command.json](/home/philip/binary-eagle-decoding/runs/spec-cuda-fix-20261031/configure-command.json).

The 32-request patched timing receipts are only two repetitions of 16 requests, with no alternating arm order. They are not acceptance-grade throughput measurements. The observed request-token/s ratios (speculative / target-only) were: Q4_K_M 4B MTP 161.97/157.67 = 1.027; Q4_K_M 9B DFlash 47.85/118.89 = 0.403; NVFP4 4B MTP 179.14/182.34 = 0.983; NVFP4 9B DFlash 52.54/127.70 = 0.412. In particular, DFlash is much slower here despite exact tokens. The audit also notes all request `timings.cache_n=0`; `tokens_cached` is final slot length, not prompt-cache hits. Summaries are in each target's `measurements/<target>/<arm>/patched/summary.json` under [spec-cuda-fix-20261031](/home/philip/binary-eagle-decoding/runs/spec-cuda-fix-20261031/).

The runtime checkout identity used to produce the copied patched source is not sealed into an immutable source manifest alongside that copy. The shortlist baseline runtime is pinned, and the patched library bytes are pinned, but the patch-source ancestry/build tree relation still needs a source archive/tree hash and reproducible build receipt before treating the result as a source-level release.

Include no-spec and the same-target MTP/DFlash controls; include Q4_0 EAGLE where it is the relevant project baseline, never substitute Q4_K_M for it.
